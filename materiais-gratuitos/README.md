# Materiais gratuitos — DP Tech na Prática

Esta área reúne os arquivos gratuitos disponibilizados nos conteúdos do DP Tech na Prática.

## Organização
- Cada quadro possui sua própria pasta.
- Dentro do quadro, cada conteúdo recebe uma pasta identificada pelo número e por um nome curto.
- Somente materiais destinados ao público devem ficar aqui.
- Arquivos internos de produção, checkpoints, masters e documentação do projeto não devem ser publicados nesta área.

Padrão:
```
materiais-gratuitos/
  atalho-dp/
    003-painel-visual-ferias/
      README.md
      prompt-mestre.txt
      planilha-ficticia-ferias.xlsx
```
