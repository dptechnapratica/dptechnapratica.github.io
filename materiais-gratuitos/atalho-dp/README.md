# Materiais gratuitos — Atalho DP

Padrão de organização dos downloads da série Atalho DP.

Cada vídeo deve possuir uma pasta própria:
```
NNN-nome-curto-do-conteudo/
```

Exemplo:
```
003-painel-visual-ferias/
```

A pasta de cada conteúdo deve conter apenas os arquivos liberados ao público e um README explicando o uso.
